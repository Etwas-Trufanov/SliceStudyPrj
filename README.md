## Векторная алгебра (2D)

### Базовые операции с векторами
- **Вектор направления линии**: `(dx, dy) = (pos2.x - pos1.x, pos2.y - pos1.y)`
- **Длина вектора**: `|V| = sqrt(dx² + dy²)`

## Геометрия отрезков

### Смещение линии (offset)
При смещении линии на расстояние `d` перпендикулярно:
- **Нормаль к линии**: `(-dy/modD, dx/modD)` — поворот вектора на 90°
- **Новая точка**: `(x + normal.x * d, y + normal.y * d)`

### Пересечение двух отрезков
Для отрезков с направлениями `(dx1,dy1)` и `(dx2,dy2)`:

**Система уравнений**:
```
P1 + t*V1 = P3 + u*V2
```
где:
- `P1, P3` — начальные точки отрезков
- `V1, V2` — векторы направлений
- `t, u` — параметры (0..1 для точек на отрезке)

**Решение через определитель**:
```
denominator = dx1*dy2 - dy1*dx2
t = ((P3.x - P1.x)*dy2 - (P3.y - P1.y)*dx2) / denominator
u = ((P3.x - P1.x)*dy1 - (P3.y - P1.y)*dx1) / denominator
```

**Условие пересечения**: `0 ≤ t ≤ 1` И `0 ≤ u ≤ 1`

### Проверка коллинеарности
**Векторное произведение** (псевдоскалярное):
```
cross(A, B) = Ax*By - Ay*Bx
```
Если `cross(V1, (P2 - P1)) ≈ 0` — векторы коллинеарны (параллельны)

## Координаты и растеризация

### Рисование линии на BMP
Алгоритм основан на разбиении по оси с большим шагом:
- Если `|dx| > |dy|` — идём по X, вычисляем Y
- Если `|dy| > |dx|` — идём по Y, вычисляем X
- Формула: `y = y1 + (dy/dx) * (x - x1)`

### Округление координат
`std::abs(std::round(value))` — приведение float к целым пиксельным координатам

## Итеративный алгоритм
- Смещение выполняется пошагово (шаг `-5` пикселей)
- После каждого шага проверка на самопересечения
- При обнаружении коллизий или параллельности — остановка
